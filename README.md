# Secure File Sharing System with Encryption in Java

## Features

- User registration
- User login
- Password hashing using PBKDF2
- File encryption using AES/GCM
- File upload
- File download and decryption
- List uploaded files
- Share encrypted files with another user

## Technologies Used

- Java 17
- Maven
- AES/GCM Encryption
- PBKDF2 Password Hashing
- File Handling
